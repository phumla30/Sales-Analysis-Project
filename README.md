# Sales Analysis Project

## Project Overview

This project analyzes sales data from January and February 2026 using Microsoft Excel. The goal is to identify sales patterns across cities, product categories, individual products, and dates.

## Tools Used

* Microsoft Excel Online
* GitHub

## Dataset

The dataset contains 30 sales records with the following fields:

* Order Date
* Order ID
* Product
* Category
* City
* Quantity
* Unit Price
* Sales

## Data Quality Checks

* Inspected column headings and data types.
* Checked for missing values.
* Checked for duplicate records.
* Verified sales calculations.

## Key Findings

* **Total Sales:** R10,760
* **Total Quantity Sold:** 124 units
* **Average Sale:** R358.67
* **Highest Individual Sale:** R1,350
* **Lowest Individual Sale:** R75
* **Highest-Selling City:** Johannesburg, with R5,460
* **Highest-Selling Category:** Electronics, with R5,220
* **Highest-Selling Product:** Headphones, with R3,600

## Visualizations

Four charts were created:

1. Sales by City
2. Sales by Category
3. Sales by Product
4. Sales Trend Over Time

## Recommendations

* Review electronics sales and stock requirements.
* Investigate factors contributing to Johannesburg's sales performance.
* Monitor product-level performance.
* Track daily sales trends to identify patterns.

## Project Files

* `Sales_Practice_Dataset.csv` — Raw sales data
* `Sales_Analysis.xlsx` — Excel analysis and charts
* `Sales_Analysis_Report.docx` — Written report

## Conclusion

This project demonstrates basic data cleaning checks, spreadsheet formulas, sales aggregation, data visualization, and business insight reporting.
